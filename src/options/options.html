About & Privacy Guarantee

Architecture details, permission justification, and privacy commitments.

Privacy-First Architecture

This extension runs entirely in your local browser sandbox. It contains zero telemetry, zero external network calls, and zero analytics. Your browsing history is never tracked, logged, or sent to external servers.

Declared Manifest Permissions

Permission Type Justification
declarativeNetRequest API Allows Chrome to block ad and tracker network requests declaratively at engine level without running background scripts on each packet.
storage API Stores your whitelist preferences, toggle states, and aggregated blocked counters locally on your device via chrome.storage.local.
<all_urls> Host Permission Enables declarative rules to intercept third-party ad server subresources requested across web pages you visit.
